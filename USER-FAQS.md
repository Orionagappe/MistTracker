# User FAQs

## Browser Extension Deactivation

**Problem**: Browser keeps redirecting to unwanted search engine (often from malicious/old extensions)

**Solution**:

### Chrome/Edge/Brave:
1. Menu (⋮) → Extensions → Manage extensions
2. Find suspected extension → Toggle OFF or Remove

### Firefox:
1. Menu (≡) → Add-ons
2. Find extension → Disable or Remove

### Safari:
1. Settings → Extensions
2. Find extension → Uncheck or remove

**Follow-up if redirects persist:**
- Clear browser cache & cookies
- Reset homepage/search engine settings (extensions often modify these)
- Restart browser

**Key insight**: Malicious extensions modify browser settings directly—disabling alone may not stop redirects without resetting those settings.
