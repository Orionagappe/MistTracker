## Domain-Specific Milestone Extensions

### Phase 17: ATOMIC PHYSICS (CURRENT)
**Core Research Question**: "Can we validate quantum atoms?"

**Milestone Types**: 12 (theory → experimental → validation → refinement → completion)

**Key Observables**:
- Orbital radius (Bohr radius, electron cloud shape)
- Energy levels (ground state, excited states, ionization)
- Transition rates (spectral lines, absorption/emission)
- Spin-orbit coupling, fine structure

**Validation Targets**:
- NIST atomic data
- Quantum mechanics predictions (Schrödinger equation)
- Experimental spectroscopy

**Output**: Validated atom models + proxies for fast evaluation

### Phase 18: SUBATOMIC PHYSICS (Next Domain)
**Core Research Question**: "Can we validate quarks and leptons within atoms?"

**New Milestone Types** (extends Phase 17):

**QUARK_MODEL_DEFINED**
- Which quark model? (Constituent, valence, sea quarks?)
- Coupling strength parameters
- Target: Nucleon structure (proton vs neutron)

**NUCLEON_COMPOSITION_VERIFIED**
- Simulated quark → nucleon interaction
- Extracted: nucleon mass, magnetic moment, form factors
- Compare vs: NIST nucleon data, deep inelastic scattering experiments

**LEPTON_BINDING_VERIFIED**
- How do electrons bind in quark-generated potential?
- Extracted: binding energy, orbital distortion from nuclear structure
- Compare vs: hyperfine splitting, isotope shifts

**QUARK_PROXY_GENERATED**
- Fast surrogate: nucleon potential without quark dynamics
- Speedup: 100x+ (skip QCD, use effective potential)

**Key Observables**:
- Nucleon form factors (charge, magnetic distributions)
- Hyperfine structure (nuclear-electron coupling)
- Isotope shifts (nuclear size variations)
- Beta decay rates (weak interaction effects)

**Validation Targets**:
- Particle Data Group (PDG) values
- Nuclear physics experiments (Fermilab, CERN)
- Precision spectroscopy (isotope shifts)

**Output**: Validated quark/lepton models enabling nuclear physics

### Phase 19-20: CHEMISTRY (Domain 3)
**Core Research Question**: "Can we model molecules and chemical reactions?"

**New Milestone Types** (extends Phase 17-18):

**BONDING_MODEL_DEFINED**
- Which bonding types? (Ionic, covalent, metallic, hydrogen)
- Which electron density approximation?
- Target: H₂ bond length, bond energy

**MOLECULAR_GEOMETRY_VERIFIED**
- Simulated atoms → molecular configurations
- Extracted: bond lengths, angles, dihedral angles
- Compare vs: X-ray crystallography, computational chemistry (DFT)

**ORBITAL_HYBRIDIZATION_VERIFIED**
- sp, sp², sp³ orbital shapes and energies
- Extracted: orbital pictures, bonding/antibonding energies
- Compare vs: MO theory, spectroscopy

**REACTION_PATHWAY_VERIFIED**
- Simulated reaction: A + B → C + D
- Extracted: activation energy, reaction rate, product distribution
- Compare vs: experimental kinetics, thermochemistry

**CHEMICAL_PROXY_GENERATED**
- Fast surrogate: molecule without full electron simulation
- Speedup: 1000x+ (skip DFT, use machine-learned force fields)
- Valid range: similar molecules, similar conditions

**Key Observables**:
- Bond lengths, angles, energies
- Orbital energies and shapes (HOMO/LUMO)
- Reaction rates and barriers
- Spectroscopic properties (IR, UV-Vis, NMR)

**Validation Targets**:
- Chemical databases (CSD, PubChem)
- Computational chemistry results (Gaussian, VASP)
- Experimental spectroscopy and kinetics
- Thermochemical tables (NIST, ICSD)

**Output**: Validated molecular and reaction models

## Database Schema for Multi-Domain Support

### New Table: `domain_milestones`
Links milestones across domains

```sql
CREATE TABLE domain_milestones (
  milestoneId VARCHAR(36) PRIMARY KEY,
  domain VARCHAR(50),           -- 'atomic', 'subatomic', 'chemistry', 'materials', 'astrophysics', 'cosmology'
  dependentDomains JSON,        -- ["atomic"] for chemistry milestones
  emergentPhenomenon VARCHAR(255),  -- "covalent bonding emerges from atomic physics"
  validationChain JSON,         -- Track how validation propagates
  FOREIGN KEY (milestoneId) REFERENCES simulation_milestones(milestoneId)
);
```

### New Table: `scale_linkages`
Maps predictions from one scale to observations at another

```sql
CREATE TABLE scale_linkages (
  linkageId VARCHAR(36) PRIMARY KEY,
  sourceDomain VARCHAR(50),
  sourceMilestoneId VARCHAR(36),
  sourceObservable VARCHAR(255),    -- "atomic ionization energy"
  targetDomain VARCHAR(50),
  targetMilestoneId VARCHAR(36),
  targetObservable VARCHAR(255),    -- "stellar opacity"
  linkageFunction VARCHAR(500),     -- Mathematical model connecting scales
  uncertaintyPropagation DECIMAL(5,2),  -- % uncertainty growth
  FOREIGN KEY (sourceMilestoneId) REFERENCES simulation_milestones(milestoneId),
  FOREIGN KEY (targetMilestoneId) REFERENCES simulation_milestones(milestoneId)
);
```

### New Table: `emergence_models`
Captures how macroscopic phenomena emerge from microscopic ones

```sql
CREATE TABLE emergence_models (
  emergenceId VARCHAR(36) PRIMARY KEY,
  microscopicDomain VARCHAR(50),
  macroscopicDomain VARCHAR(50),
  emergentProperty VARCHAR(255),    -- "color" emerges from electronic structure
  derivationMethod VARCHAR(50),     -- "averaging", "coarse-graining", "statistical"
  validationStatus ENUM('untested', 'passed', 'failed'),
  residualError DECIMAL(8,6),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## Architectural Principles

### 1. Domain Autonomy
Each domain validates independently:
- Phase 17 succeeds OR fails independent of Phase 18
- No cascading validation failures across domains

### 2. Emergent Linkage
Larger scales emerge from smaller scales:
- Molecules don't just exist; they emerge from atomic physics
- Stars don't just exist; they emerge from plasma physics
- Universe doesn't just exist; it emerges from quantum fields

### 3. Validation Propagation
Uncertainties grow with scale:
- Atomic model ±1% → Molecular prediction ±2% → Stellar prediction ±5%
- Track cumulative error to identify critical atomic/molecular uncertainties

### 4. Reversible Inference
If cosmological observations don't match predictions:
- Back-propagate through domain chain
- Identify which domain has the fault
- Re-validate that domain with finer granularity

### 5. Proxy Composition
Each domain has its own proxy:
- Atomic proxy: 94% accurate, 25x speedup
- Molecular proxy: 96% accurate, 100x speedup
- Stellar proxy: 92% accurate, 1000x speedup
- Composite proxy: ? accurate, 1000000x speedup
