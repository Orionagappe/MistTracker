## Cross-Domain Research Patterns

### Pattern 1: Emergence Chains
**Question**: "How does macroscopic property emerge from microscopic?"

```
Covalent bonding (chemistry) 
  ← emerges from electron overlap (atomic)
    ← emerges from electron probability density (quantum)

Stellar luminosity (astrophysics)
  ← emerges from fusion reaction rate (subatomic)
    ← emerges from quantum tunneling probability (quantum)

Galaxy rotation (cosmology)
  ← emerges from gravitational potential (astrophysics)
    ← emerges from mass distribution (materials)
      ← emerges from... what? (dark matter missing)
```

### Pattern 2: Uncertainty Propagation
**Question**: "How do atomic uncertainties affect cosmic predictions?"

```
Atomic model: ±1% uncertainty
  ↓ propagates to
Molecular model: ±2% uncertainty
  ↓ propagates to
Material model: ±3% uncertainty
  ↓ propagates to
Stellar model: ±5% uncertainty
  ↓ propagates to
Cosmological model: ±10-15% uncertainty
```

### Pattern 3: Reverse Inference
**Question**: "If cosmology doesn't match observations, which domain needs fixing?"

```
Observation: Galaxy rotates too fast

Compare:
- Astrophysics prediction (assumes normal matter)
- Cosmological observation (rotating faster than predicted)

Back-propagate:
- Is stellar physics wrong? (No, Phase 23 validated)
- Is material physics wrong? (No, Phase 21 validated)
- Is chemical physics wrong? (No, Phase 19 validated)
- Is atomic physics wrong? (No, Phase 17 validated)
- Is subatomic physics wrong? (No, Phase 18 validated)

Conclusion: Missing physics = **dark matter** (Phase 25 to define)
```

### Pattern 4: Proxy Composition
**Question**: "How accurate is composite proxy through all scales?"

```
Atomic proxy: 94% accurate, 25x speedup
Molecular proxy: 96% accurate, 100x speedup
Material proxy: 97% accurate, 1000x speedup
Stellar proxy: 92% accurate, 1000000x speedup

Composite: 94 × 96 × 97 × 92 = ?

Each proxy introduces error. Eventually drops below useful threshold.
Phase 25+ finds: "Beyond stellar scale, which proxy breaks down?"
```

### New Tables

2. **scale_linkages**
   - Maps predictions from one scale to observations at another
   - Tracks uncertainty propagation factor
