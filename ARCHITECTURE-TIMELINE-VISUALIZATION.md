### Query 1: Emergence Chain
```

    ← electron overlap (atomic layer)
      ← electron probability density (quantum layer)
        ← Schrödinger equation (fundamental)

Output: Understanding emergence across 3 scales

### Query 2: Uncertainty Propagation
```
Input: "How accurate is cosmological prediction?"

Propagate forward:
  Atomic model: ±1% error
    ↓ feeds into molecular model
  Molecular model: ±2% error
    ↓ feeds into material model
  Material model: ±3% error
    ↓ feeds into stellar model
  Stellar model: ±5% error
    ↓ feeds into cosmological model
  Cosmological model: ±15% error

Output: Know uncertainty budget at each scale
```

### Query 3: Reverse Inference
```
Input: "Why is galaxy rotation not matching prediction?"

Analysis:
  Observation shows: Galaxy rotates too fast
  Stellar model predicts: Should rotate slower
  
  Back-propagate:
    □ Phase 23-24 stellar physics: validated ✓
    □ Phase 21-22 material properties: validated ✓
    □ Phase 19-20 chemistry: validated ✓
    □ Phase 18 nuclei: validated ✓
    □ Phase 17 atoms: validated ✓
    
  Conclusion: Missing physics = dark matter
  
Output: Identified exactly which domain needs extension
```

### Query 4: Proxy Fidelity
```
Input: "How accurate is composite proxy through all scales?"

Check:
  Atomic proxy: 94% accurate
  × Molecular proxy: 96% accurate
  × Material proxy: 97% accurate
  × Stellar proxy: 92% accurate
  ─────────────────────────
  = Composite accuracy drops significantly

Output: Find which proxy is breaking down
