## Core Design: The Game

**Codename:** The Game  
**Duration:** 23 real-time years (2026-2049)  
**Player Start:** ~100, scaling to ~100,000  
**Core Mechanic:** Reputation as the only measure of success  

### Key Features

1. **Starts with Complete Blackness**
   - No UI, no instructions, no narrative
   - Players must discover interaction is possible
   - First action is binding consent to rules

2. **Reputation-Only Success Measurement**
   - No timeline achievement = success
   - No output volume = success
   - No speed = success
   - **Only:** Truthfulness (reputation accuracy)

3. **Objective Lying Detection**
   - MistTracker substrate provides ground truth
   - Claims compared to objective reality (atomic physics, emergence metrics, consensus)
   - Reputation penalties automatic and deterministic
   - Ejection at reputation threshold (no appeals)

4. **Collaboration Mechanics**
   - Shared claims can be verified by multiple players
   - Consensus mechanism prevents simple majority lying
   - Collaborative bonuses encourage truthful teamwork
   - Byzantine tolerance: up to 33% malicious validators

5. **The Key Discovery**
   - Not explicitly hidden; must be recognized
   - Pattern recognition across entire game
   - Recognition = understanding reputation-only system
   - Liberation = reward for discovering key

## Key Innovation: Reputation as Cryptographic Commitment

**Why This Matters:**
- Reputation creates non-repudiation (players can't deny their history)
- Objective measurement prevents social engineering
- Cryptographic signing makes lying detectable
- Byzantine consensus prevents single-point truth corruption
- Truthfulness becomes the only viable strategy

**How It Works:**
1. Player makes claim (cryptographically signed)
2. System measures objective reality (MistTracker)
3. Comparison determines accuracy
4. Reputation adjusted automatically
5. Player cannot deny or dispute (signature + measurements are public)
