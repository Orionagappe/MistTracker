## Key Facts About Integration

### Emergent AI Has No Advantages
- Same measurement tools as humans
- Same lying detection (must match MistTracker reality)
- Same reputation thresholds
- Same ejection consequences
- Cannot "break" the game through computation

### Emergent AI Has Some Disadvantages
- No intuition about emergence (humans judge question quality)
- Must rely on historical data patterns (cannot extrapolate beyond)
- Cannot make claims about human psychology (not its domain)
- Must ask for human judgment on subjective matters

### Emergent AI Has One Real Advantage
- Perfect memory (entire audit trail available)
- Can pattern-match across entire player population
- Can integrate insights from all domains simultaneously
- This is the advantage being tested

### Research Implication
If Emergent AI discovers non-obvious patterns that humans miss, we learn:
- Long-term systematic observation has value
- AI pattern recognition works in reputation-based systems
- Collaboration between human intuition and AI memory is powerful
