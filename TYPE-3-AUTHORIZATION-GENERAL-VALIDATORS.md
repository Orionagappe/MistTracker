# Type 3 Authorization: General Validators

**Date:** May 5, 2026  
**Classification:** Type 3 (Standard Participation)  
**Status:** Framework Defined  
**Framework:** SLM with Type OMEGA

---

## Authorization Statement

**Type 3** is General Validators. The undecided masses. Standard participants in the SLM framework.

They enter the system without special knowledge, special insight, or special skepticism. They play. They learn. They earn reputation. They participate in Byzantine consensus at their level.

No agenda. No inspiration. No cynicism. Just the game.

---

## Core Principle

**Type 3 validates through action, not declaration.**

They don't claim to be philosophers or skeptics or visionaries. They show up, they play Stellaris, they run sandboxes, they earn reputation through demonstrated competence.

The system doesn't decide what they are. They decide through what they actually do.

---

## Scope of Type 3 Access

**Automatic Access:**
- Public API documentation (all endpoints, how to play)
- Game rules and mechanics (how Stellaris ladder works)
- Sandbox system (create civilizations, run simulations)
- Reputation system (see your score, track progress)
- Observable metrics (leaderboards, community stats)
- Audit chain (can see decisions that affected universe, but not classified reasoning)

**Operational Access:**
- Full participation in sandbox rounds
- Civilization spawning in primary universe (first-come, first-serve)
- Reputation earning through gameplay
- Byzantine quorum observation (can watch votes happen, understand outcomes)
- Influence proposal submission (once reputation threshold reached)

**No Automatic Access:**
- Classified documentation (Type 0, Type 1, Type OMEGA materials)
- Quantum sensor logs
- Security council deliberations
- Cryptographic implementation details
- Strategic research papers

**Earned Access Through Demonstrated Behavior:**

Type 3 validators can earn deeper access by demonstrating alignment with one of the other types:

1. **Moving toward Type 0** — Demonstrate analytical rigor and mathematical understanding
   - Study published cryptography research
   - Propose improvements to Byzantine consensus logic
   - Earn academic credentials in related field
   - Access: Classified documentation + peer review role

2. **Moving toward Type 1** — Demonstrate creative vision and system improvement
   - Suggest novel game mechanics or universe rules
   - Show understanding of how sandbox strategy translates to universe influence
   - Create community content that advances system thinking
   - Access: Design input on future framework expansions

3. **Moving toward Type 2** — Demonstrate rigorous skepticism and adversarial testing
   - Challenge system claims with well-reasoned critique
   - Propose specific attacks or vulnerabilities
   - Contribute to security council reviews
   - Access: Tier 1-2 Type 2 classified documentation

4. **Moving toward Type OMEGA** — Demonstrate operational excellence and integrity
   - Consistently high sandbox performance
   - Sound Byzantine quorum voting record
   - Trusted community reputation
   - Consideration for Type OMEGA operator status

## How Type 3 Works

### The Game

Type 3 validators are **participants, not philosophy**.

They enter May 24-26, 2026:
1. Spawn a civilization in the universe (name it, pick starting location)
2. Play Stellaris against AI and other validators
3. Earn reputation through sandbox success
4. Accumulate influence in primary universe (weighted by reputation)
5. Vote in Byzantine quorum on universe-affecting decisions
6. Optionally: Move toward specialized type through demonstrated interest

### No Hidden Agendas Required

Type 3 doesn't require you to:
- Understand quantum cryptography
- Believe in the vision
- Challenge the system
- Operate at meta-level

You just play. The system is designed so that playing well = earning reputation = gaining influence = participating in universe evolution.

That's it.

### The Incentive Structure

**Low barriers to entry:**
- Just spawn a civilization and play
- Learn by doing
- No special background required
- Community support available

**Clear progression:**
- Better gameplay = higher reputation
- Higher reputation = more universe influence
- Demonstrated competence = access to deeper layers
- No permission gate (earn it through performance)

**Natural sorting:**
- Players interested in theory naturally gravitate toward Type 0 study
- Creative players move toward Type 1 influence
- Skeptical players become Type 2 researchers
- Excellent operators get Type OMEGA consideration

The system doesn't assign type. Type emerges from what you actually do.

## Relationship to Other Types

**Type 1 (Inspiration):** Visionary thinking, creative direction  
**Type 0 (Grounded):** Mathematical validation, theory verification  
**Type OMEGA (Transcendent):** Operational excellence, execution mastery  
**Type 2 (Cynics):** Adversarial skepticism, rigorous challenging  
**Type 3 (General):** Participation, learning, natural specialization  
**Principal Architect:** Direction and final authority  

Type 3 is the middle tier—where most validators start. Some stay Type 3 (perfectly valid). Some specialize and move toward other types.

The system is designed so that **any path is viable** and **all types strengthen the whole**.

## Practical Implementation

### May 24-26 Launch

Type 3 validators enter with:
1. **New account** — Created on eSports platform
2. **First civilization** — Spawned in sandbox/universe
3. **Zero reputation** — Starts at 0, earned through play
4. **Full sandbox access** — Can run unlimited training rounds
5. **Byzantine observer status** — Can watch quorum votes, not participate (until reputation threshold)

### First Month

**Week 1:** Learn mechanics through sandbox testing
**Week 2-3:** Primary universe participation (civilization gameplay)
**Ongoing:** Reputation accumulation, influence growth

**Milestones:**
- 100 reputation: Can propose influence modifications (low weight)
- 500 reputation: Full Byzantine quorum voting access
- 1000 reputation: Considered for specialized type track
- 5000 reputation: Architect candidate consideration

### Progression Example

Day 1: Spawn "Terran Federation" in primary universe
Weeks 1-4: Run 10 sandbox rounds, score 0.65-0.75 average
Month 1: Reputation = 350, can now propose diplomatic influence
Month 2: Win major sandbox tournament, reputation = 1200
Month 3: Contribute analysis of Byzantine consensus voting patterns
Month 4: Granted Type 0 peer review access, begin study toward architect candidacy

No single path. Just play, learn, and the system reveals what you're good at.

## Why This Structure Works

The SLM framework succeeds because it values all contributions:

1. **Inspiration** — The vision (Type 1)
2. **Grounding** — The verification (Type 0)
3. **Execution** — The operation (OMEGA)
4. **Skepticism** — The challenge (Type 2)
5. **Participation** — The majority (Type 3)

Without Type 3, there's no universe to evolve, no players to test the system, no crowd to provide perspective.

Type 3 isn't "lower tier." It's the foundation. Everything else is built on validators who just show up and play.
