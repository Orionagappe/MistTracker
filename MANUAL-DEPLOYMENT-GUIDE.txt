=========================================================
  MISTTRACKER - MANUAL DEPLOYMENT GUIDE
  Degraded Hardware Validation Test
=========================================================

OBJECTIVE:
Deploy missing Phase 17.5-Beta modules and run hardware
fitness validator on Devuan system (10.144.113.100)

SYSTEM INFO:
- Target: Devuan Excaliber (6.7GB RAM, degraded hardware)
- Deployment path: /home/orion/Desktop/misttracker/
- Flash drive location: d:\misttracker-deployment\

=========================================================
STEP 1: PREPARE FLASH DRIVE ACCESS
=========================================================

On Devuan system:

1a. Insert flash drive and identify mount point:
    $ lsblk
    $ mount | grep media
    
    Look for: /media/orion/[flashdrive-name] or /mnt/usb

1b. If not automatically mounted, mount manually:
    $ sudo mkdir -p /mnt/usb
    $ sudo mount /dev/sd[X]1 /mnt/usb
    
    (Replace sd[X] with actual device from lsblk output)

1c. Verify flash drive contents:
    $ ls /mnt/usb/
    
    Expected files:
    - phase-17-5-beta-aggregator.js
    - phase-17-5-beta-cve-forecaster.js
    - phase-17-5-beta-friction-predictor.js
    - phase-17-5-beta-stability-modeler.js
    - hardware-fitness-validator.js
    - phase-17-5-beta-network-predictor.js

=========================================================
STEP 2: COPY MISSING MODULES
=========================================================

On Devuan system:

2a. Navigate to misttracker directory:
    $ cd /home/orion/Desktop/misttracker

2b. Copy all required modules from flash drive:
    $ cp /mnt/usb/phase-17-5-beta-aggregator.js .
    $ cp /mnt/usb/phase-17-5-beta-cve-forecaster.js .
    $ cp /mnt/usb/phase-17-5-beta-friction-predictor.js .
    $ cp /mnt/usb/phase-17-5-beta-stability-modeler.js .
    $ cp /mnt/usb/phase-17-5-beta-network-predictor.js .
    $ cp /mnt/usb/hardware-fitness-validator.js .

2c. Verify all files are present:
    $ ls -la *.js
    
    Expected 7 files:
    - hardware-fitness-validator.js
    - phase-17-5-beta-aggregator.js
    - phase-17-5-beta-cve-forecaster.js
    - phase-17-5-beta-extended-aggregator.js (already present)
    - phase-17-5-beta-friction-predictor.js
    - phase-17-5-beta-network-predictor.js
    - phase-17-5-beta-stability-modeler.js

2d. Check file sizes to confirm copy success:
    $ ls -lh phase-17-5-beta-*.js hardware-fitness-validator.js

=========================================================
STEP 3: RUN HARDWARE FITNESS VALIDATOR
=========================================================

On Devuan system:

3a. Start validator with output to file (5-10 minutes):
    $ node hardware-fitness-validator.js > validator-results.txt 2>&1 &
    
    [or for verbose output]
    
    $ nohup node hardware-fitness-validator.js > validator-results.txt 2>&1 &

3b. Monitor progress:
    $ tail -f validator-results.txt
    
    (Press Ctrl+C to stop monitoring)

3c. Check if validator is still running:
    $ ps aux | grep hardware-fitness-validator
    
    If it shows in the list, it's still running.
    If no output, the test has completed.

3d. After ~5-10 minutes, check the results:
    $ wc -l validator-results.txt
    $ tail -50 validator-results.txt

=========================================================
STEP 4: RETRIEVE RESULTS
=========================================================

On Windows system (after test completes):

4a. Copy results file back to Windows:
    $ scp orion@10.144.113.100:/home/orion/Desktop/misttracker/validator-results.txt .

4b. Or manually via flash drive:
    On Devuan:
    $ cp validator-results.txt /mnt/usb/
    
    Then retrieve flash drive and copy to Windows.
